# GestiShop — Gestion des produits

## Description
GestiShop est une application web qui permet de gérer une liste de produits.

## Fonctionnalités
- Afficher les produits dans un tableau.
- Ajouter un produit.
- Modifier un produit.
- Supprimer un produit.
- Rechercher un produit par son nom.
- Filtrer les produits par catégorie.
- Afficher les statistiques des produits.
- Sauvegarder les produits dans le navigateur avec `localStorage`.
- Réinitialiser la liste des produits.

## Technologies utilisées
- HTML
- CSS
- JavaScript
- localStorage et JSON

## Lancement
Ouvrir le fichier `index.html` dans un navigateur pour utiliser l'application avec un serveur local (extension Live Server de VS Code)
